# Measurement notes

Source evidence: the original team report and six supplied laboratory photographs.

## Clean waveform photograph

CH1: 540 mVpp, 999.8 Hz. CH2: 1.61 Vpp, 1.0005 kHz. Taking CH1 as input and CH2 as output, consistent with the report, the voltage gain is 2.9815 V/V. Relative error from the target of 3 is 0.6173%. The displayed sine waves are approximately in phase. No THD measurement is available, so no numerical distortion specification is claimed.

## Report operating point

The report separately records 0.504 Vpp input and 1.54 Vpp output. Their ratio is 3.0556 V/V and target-relative error is 1.8519%. These values differ from the supplied standalone photograph and are retained as a distinct report observation.

## Clipping photograph

CH1: 5.3 Vpp, 1.0000 kHz. CH2: 7.8 Vpp, 1.0002 kHz. The output has flat peaks. This is evidence of saturation at that operating point, not a measurement of the exact clipping threshold. Probe attenuation, coupling settings, and load configuration were not separately documented for these photographs.

## Equipment photographs

The function generator is set to a 1 kHz sine wave, 500 mVpp, zero offset, with its load setting at High Z. The supply photograph displays 9.0 V on the active channel. These are photographed settings; they do not establish that every waveform capture used exactly the same setup.

## Evidence boundaries

The report contains estimated input-sweep and frequency-response entries alongside measured values. A complete raw sweep is not supplied. The report's conclusion states that the exact clipping onset, high-frequency bandwidth, and overload behavior were not fully established; its buzzer test produced no audible output. The standalone clipping photograph adds visual evidence of clipping but does not resolve those other gaps.

The original schematic is reproduced for documentation. It is not an independently validated reconstruction of every breadboard connection.
